# Vanguard Brief
Write posts as .md files in `posts/` (copy the sample), preview with `node build.js serve`, then `git add . && git commit -m "new post" && git push`. GitHub builds and publishes it automatically.
Images go in `static/images/` and are used as `![caption](/images/name.jpg)`. Add a 1200x630 `default.jpg` there for LinkedIn previews.
